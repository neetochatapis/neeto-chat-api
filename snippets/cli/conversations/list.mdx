| Flag | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--status` | `string` |  |  | Filter by status (comma-separated, e.g. open,closed) |
| `--updated-after` | `string` |  |  | Only conversations updated after this ISO8601 timestamp |
| `--sort` | `string` |  | `created_at` | Sort field: created_at or updated_at |
| `--order` | `string` |  | `asc` | Sort direction: asc or desc |
| `--page` | `int` |  | `0` | Page number |
| `--page-size` | `int` |  | `0` | Items per page (max 100) |
