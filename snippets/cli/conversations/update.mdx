| Flag | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--title` | `string` |  |  | Conversation title |
| `--status` | `string` |  |  | Conversation status |
| `--priority` | `string` |  |  | Conversation priority |
| `--assignee-email` | `string` |  |  | Agent email to assign |
| `--group-name` | `string` |  |  | Group name to assign |
| `--tag` | `stringArray` |  | `[]` | Tag name to apply (repeat the flag for more than one) |
| `--ticket-field` | `stringToString` |  | `[]` | Custom field value as name=value (repeat the flag for more than one) |
| `--read` | `bool` |  | `false` | Mark the conversation as read |
