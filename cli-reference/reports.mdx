A report aggregates conversation activity over a date range. For fields and
response details, see the [Reports API reference](/api-reference/reports/get-conversations).

## Choose the date range

Every report takes the same three range flags. Pass `--range-type` for a named
window, such as `last_7_days` or `last_30_days`. Pass `--start-date` and
`--end-date` together for an exact range instead, with or without
`--range-type custom_duration`:

```bash
neetochat reports conversations --range-type last_30_days
neetochat reports conversations --start-date 2026-07-01 --end-date 2026-07-31
```

Dates are `YYYY-MM-DD`. With all three flags omitted, the range defaults to
`all_time`. Every figure compared against the previous period of the same
length comes back as `present`, `previous` and `change_percentage`.

## Show the conversations report

Conversation volume over the range: opened, closed, replied to, and left
unassigned, each compared against the immediately preceding period of the
same length.

```bash
neetochat reports conversations --range-type last_30_days --json
```

## Show the customer satisfaction report

How customers rated conversations on each day of the range, broken down into
`good`, `okay` and `bad`. `data` is `null` when the workspace has no rating
question configured on its post-chat survey.

```bash
neetochat reports customer-satisfactions --range-type last_7_days --json
```

<ReportsCustomerSatisfactionsFlags />

```json
{
  "data": {
    "dates": ["2026-10-14", "2026-10-15", "2026-10-16", "2026-10-17"],
    "data": [
      { "name": "good", "values": [3, 2, 4, 3] },
      { "name": "okay", "values": [1, 2, 1, 1] },
      { "name": "bad", "values": [1, 1, 1, 1] }
    ],
    "percentages": { "good": 57, "okay": 24, "bad": 19 }
  }
}
```

Without `--json`, the pretty output is a table with one row per date and one
column per rating.

## Show the groups report

The same conversation metrics as the conversations report, broken down by
group instead of for the whole workspace. All groups are returned; the
response is not paginated.

```bash
neetochat reports groups --range-type last_30_days --json
```
